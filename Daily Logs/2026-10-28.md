## Problems/Solutions Ran Into

### Git Repository Not Recognized

Problem:
Git reported that the new documentation directory was not a repository.

Solution:
Found that the hidden `.git` directory had not been copied. Moved the complete repository and verified the original Git history was available.

### Unexpected Modified Files

Problem:
After moving the repository to NAS storage, Git showed several modified files.

Solution:
Investigated differences in file permissions and metadata when using Git over SMB/CIFS. Reviewed the changes before staging and committing.

### Git Across Multiple Computers

Problem:
The repository is now accessible from multiple Linux computers through the NAS.

Solution:
Decided to avoid simultaneous Git operations against the shared repository. Git changes should be completed on one machine before using the repository from another.

### Outdated Documentation

Problem:
Several existing Markdown files no longer fully represented the current homelab.

Solution:
Reviewed and updated the infrastructure documentation, including new services, hardware, storage, and network architecture.
