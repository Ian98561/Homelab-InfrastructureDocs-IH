### Problems/Solutions Ran Into:

- Desktop was not immediately using Pi-hole after changing Eero DNS
  - Checked DNS configuration using resolvectl
  - Desktop initially showed the previous ISP DNS servers
  - Solution: disconnected and reconnected Ethernet
  - Result: DNS-based ad blocking worked successfully

- Joplin returned an Invalid origin error
  - Error: Invalid origin: http://joplin.example.internal:22300
  - Cause: Joplin's configured APP_BASE_URL did not match the new local hostname
  - Solution: updated APP_BASE_URL inside /opt/joplin/compose.yaml
  - New value (sanitized): http://joplin.example.internal:22300
  - Restarted the application through Docker Compose
  - Result: Joplin worked with the new hostname

- Permission denied while editing compose.yaml
  - Problem: normal user did not have permission to modify the Compose file
  - Solution: edited the file using sudo
  - Applied the updated configuration through Docker Compose
