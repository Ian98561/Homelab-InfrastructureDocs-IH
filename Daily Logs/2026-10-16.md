# 2026-10-16 — LXC Networking, NAS Mount, and Media Server

> Public-facing version: host identifiers, private addresses, share names, and account details are generalized.

## Notes

- Resolved startup/networking failures affecting the **file-server LXC** and **Pi-hole LXC**. Both containers had been configured with `ip6=dhcp` on a Proxmox bridge; changed this to `ip6=manual` to avoid DHCPv6 startup timeouts. Both networking services returned to an active state with IPv4 connectivity.
- Verified the file server and Pi-hole on their assigned private LAN addresses. A local `dig @127.0.0.1 google.com` check on Pi-hole returned `NOERROR`. Long-term DHCP/network stability still needs monitoring.
- Mounted the NAS Samba share (`//<fileserver-lan-ip>/<share-name>`) on the Linux workstation at `/mnt/<nas-share>`. Configured a persistent systemd automount through `/etc/fstab` with a separately protected SMB credentials file.
- Built a **media-server Proxmox VM** using Debian 13 for household movies and television.
- Exposed NAS media storage to the media VM through **VirtioFS**, rather than SMB. Mounted it persistently at `/mnt/media` with `/etc/fstab`; established a media layout for downloads, movies, and television.
- Set up Docker and Docker Compose under `/opt/media-stack`, with services including Jellyfin, qBittorrent, Radarr, Sonarr, Prowlarr, and Seerr. The container/media path conventions use `/data` internally.
- Confirmed media-storage write access with the applicable UID/GID 1000 mappings. Docker services and initial Jellyfin playback/library behavior were tested successfully.

- **SMB share allowed access but not deletion in some folders:** Narrowed the issue to underlying Samba/ZFS ownership or permissions rather than simply the workstation's mount options. A confirmed permanent fix was not recorded.
- **VirtioFS media writes initially needed permission alignment:** Adjusted ownership/mapping around UID/GID 1000 and confirmed write tests.
- **ZFS degraded state:** Recognized it was caused by the deliberately removed drive; no replacement was installed during this session.
