### Problems/Solutions Ran Into:
- CGNAT prevents normal public IPv4 port forwarding
  - ISP assigns the router an address within the CGNAT range
  - External connection attempts did not reach `GameServer1`
  - Solution: use Playit.gg, use Tailscale, or purchase a public/static IPv4 from the ISP

- Valheim crossplay connection issues
  - PlayFab registered the server and generated join codes
  - Clients froze or failed when attempting to connect using the join code
  - Temporarily switched to Steam-only networking

- IPv6 lookup errors
  - Valheim repeatedly attempted to detect a public IPv6 address
  - `GameServer1` did not have usable public IPv6 connectivity
  - Disabling IPv6 did not resolve the issue, so the change was not made permanent

- Valheim startup issue
  - Server initially stopped during startup due to configuration/password issues
  - Fixed server configuration and confirmed successful server startup

- External port forwarding did not work
  - Confirmed Valheim was listening correctly on the expected UDP ports
  - Confirmed Debian firewall was not blocking traffic
  - Confirmed LAN UDP traffic reached the VM
  - Determined the failure was caused by upstream CGNAT rather than Proxmox, Debian, or Valheim
